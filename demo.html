Clasificador de facturas

Carga un ZIP o varios XML dummy. La demo extrae proveedor, monto y clasifica gastos deducibles o no deducibles con reglas simples de ejemplo.

Descargar ZIP demo
Funciona con XML dummy o archivos de texto con datos simulados.
Regla demo: el campo Concepto funciona como un catálogo de ejemplo. Conceptos como “Papelería y oficina”, “Software administrativo”, “Equipo de cómputo”, “Publicidad digital” e “Internet empresarial” se clasifican como deducibles. Conceptos como “Consumo personal”, “Entretenimiento”, “Regalo” o “Sin comprobante” se clasifican como no deducibles.

Forecast de inventario

Carga ventas históricas y obtén una estimación simple de demanda mensual e inventario sugerido por producto.

Descargar template
Columnas sugeridas: Mes, Producto, Ventas, Inventario.
Cómo funciona: esta demo calcula automáticamente un inventario objetivo usando la demanda estimada + 25% de colchón de seguridad. Si el inventario actual es menor al objetivo, el sistema calcula automáticamente la compra sugerida.
Regla demo: se usa promedio mensual por producto + 25% de colchón de seguridad.
